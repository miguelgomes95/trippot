# TripPot

**An AI agent that runs the money side of group trips.** It reads booking confirmations, splits costs across travellers, collects with PayPal invoices, chases late payers, and pays suppliers automatically once the pot is funded.

Built for the [PayPal AI Hackathon](https://paypalaihackathon.devpost.com/) (2026).
